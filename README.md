# Unit 6: Version Control & Professional Practices

> **Python Fundamentals**

Git fundamentals, PEP 8, and using the skills from Units 1-5 together.

## New here?

If this is your first time opening a unit repo, start with
[**GETTING_STARTED.md**](GETTING_STARTED.md) — it covers opening this
Codespace, using Jupyter notebooks, doing the exercises, and checking your
work. You don't need to install anything.

## Learning objectives

By the end of this unit you will be able to:

- Use git add, commit, push, and pull in a real workflow
- Apply PEP 8 conventions to existing code
- Describe what pandas does and how it extends what you have learned
